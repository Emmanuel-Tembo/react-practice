# Travel Journal

Created a travel journal using react. 

## How to run local

1. make sure u have node.js installed
2. clone repo into local through terminal

```md
    git clone https://github.com/Emmanuel-Tembo/react-practice.git
```
3. cd into react practice

```
    cd react-practice
```
4. install node_modules

```
    npm install node modules
```

5. run the app

```
    npm run dev
```
